TKD Trainer (PWA) - Hosting / Anleitung
1. Den ganzen Ordnerinhalt (index.html, fragen.js, sw.js, manifest.webmanifest, icons/) unverändert auf einen statischen HTTPS-Host laden, z. B. GitHub Pages oder Netlify Drop (drop.netlify.com).
2. iPhone: Link in Safari öffnen > Teilen > "Zum Home-Bildschirm". Android: Chrome > Menü > "App installieren".
3. Daten liegen nur lokal auf dem Gerät (localStorage). Sicherung: Profil > Sicherung.
Fragenkatalog: fragen.js (alle eingebauten Fragen). index.html enthält nur Oberfläche und Logik.
Update: Dateien ersetzen; in sw.js die Version (V='tkd-v2') erhöhen, damit Geräte neu laden.
