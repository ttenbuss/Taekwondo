TKD Trainer (PWA) - Hosting / Anleitung
1. Ordnerinhalt unverändert auf einen statischen Host (HTTPS) laden, z. B. GitHub Pages oder Netlify Drop (drop.netlify.com).
2. iPhone: Link in Safari öffnen > Teilen > "Zum Home-Bildschirm". Android: Chrome > Menü > "App installieren".
3. Daten liegen nur lokal auf dem Gerät (localStorage). Sicherung: Profil > Sicherung.
